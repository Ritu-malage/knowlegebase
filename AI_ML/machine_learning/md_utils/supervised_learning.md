
### Working of supervised learning
- Training dataset is passed as an input to the learning algorithm
- The learning algorithms learns patterns
- This algorithm then produces a function f
- To the function a new unseen data is passed and then it predicts the output
- The function "f" is called the model.
- If the function is linear/straight line then $y = mx+c$ or $f(X) = wx+b$
- The w and b are called the parameters of the model
