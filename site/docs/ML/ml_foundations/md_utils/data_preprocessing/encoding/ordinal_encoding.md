# Ordinal Encoding
- Also known as **numerical encoding**.  
- Example: Feature named "skill level" with values `beginner`, `intermediate`, and `professional`.  
- These categories can be mapped to numbers:  
  - beginner = 0  
  - intermediate = 1  
  - professional = 2  
- However, this numeric assignment may incorrectly imply an **order or magnitude relationship** (e.g., professional being “twice” more important than the intermediate).  
- Ordinal encoding essentially assigns **index values** to each unique category.
