# Label Encoding
- A  unique integer value to each of the category
- This  some kind of order that is the one with the higher value might might be given higher weightage

# Went to use

- When the categories have Order associated with it
- Eg: In the case of values like low medium high, we know that low < Medium < High Thus, higher integer value can be assigned to the category high
- Low = 0, Medium = 1, and High = 2


# Cons

- Induces fall ordering
- Misleads distance based algorithms
