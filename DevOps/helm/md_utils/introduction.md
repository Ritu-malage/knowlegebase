# Helm
- Its a package manager for kubernetes
- Its like homebrew, apt (Linux system package managers), pip(package manager for libraries) but for kubernetes. These are all used to install applications on your system. Whereas Helm is used to install, update, and rollback kubernetes applications
- Its a collection of YAML files that have been bundled together
- Helm charts for popular softwares are available in public repositories for use
- It allows use to use templating which allows us to costumize the applications based on your needs by providing your own values to override the default values


# Helm Chart
- Bundle of YAML files
- Its required to create kubernetes application

# Config Values
- Named as `values.yaml` 
- Its a dynamic configuration file
- It helps in customizing the deployment of the Helm charts
